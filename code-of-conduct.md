# Code of conduct

Be welcoming, respectful and specific. Critique the work, not the person. Respect different backgrounds, experience levels and communication styles.

Harassment, discriminatory language, threats, sexual attention, doxxing and publishing private information are unacceptable. Do not use issues or pull requests for spam or personal disputes.

This applies to repository issues, pull requests and project discussions. Maintainers may edit or remove harmful content and restrict participation after reviewing the context. Enforcement should be proportionate, consistent and respectful of confidentiality.

Report problems through the maintainer contact on the repository owner's GitHub profile. Do not post sensitive evidence in a public issue. A report involving a maintainer may instead be submitted through GitHub's abuse-reporting channel. Reports are reviewed in good faith; retaliation is not permitted.
